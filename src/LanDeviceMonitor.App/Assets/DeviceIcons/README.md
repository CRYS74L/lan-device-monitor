# 自绘设备图标

这 16 个 SVG 按本项目旧网页版的图形风格重新绘制：24×24 画布、1.65 线宽、圆角端点与连接、统一的蓝色描边，优先使用真实设备外轮廓。路由器采用双天线机身；平板、显示器、电视、检测仪与传感器通过外形和内部特征区分；摄像头采用镜头机身与底座。

此目录是桌面与网页设备图标的共同源。修改后运行 `scripts/build-device-icons.py`，生成 `Controls/DeviceIconCatalog.cs` 与 `Web/device-icons.js`。不要只修改某一端的生成文件。每条独立 SVG 路径分别转换，避免相对坐标串接造成越界。

这套图标不取自 Lucide；dev.230 的第三方源保留在 Git 历史中。
