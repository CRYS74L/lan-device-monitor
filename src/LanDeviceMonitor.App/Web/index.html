第一次使用

  1. 确认浏览器地址栏没有证书警告。仅跳过警告无法使用通知。
  2. iPhone / iPad：在浏览器分享菜单中选择「添加到主屏幕」，然后从主屏幕打开。
  3. 点击「启用通知」，允许系统通知，再发送一条测试。

部分安卓浏览器不支持 Web Push，或系统/网络限制推送。显示“已订阅”不代表手机一定收到，请实测锁屏通知。

手机离开局域网仍可能收到通知，打开详情时需要重新连接此局域网。电脑必须保持运行。

连接与隐私

此页面只读展示监控数据。访问码仅存于当前浏览器；推送订阅加密保存在电脑上。通知内容采用 Web Push 加密，投递仍依赖浏览器厂商的互联网推送服务。

退出会尝试撤销本设备订阅；若电脑离线，需在浏览器设置中撤销通知权限，或在电脑上重置所有授权。
