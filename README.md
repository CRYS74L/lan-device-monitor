# 局域网设备助手

一个面向 Windows 11 的原生桌面工具，通过小米路由器管理接口查看局域网设备。

## 功能

- 实时查看设备在线状态、上传/下载速度和累计流量；
- 从工具首次运行起持续记录设备上线与离线历史；
- 根据路由器设备名识别手机、电脑、空调、灯、插座、音箱、路由器等设备类型；
- 自定义设备名称、类型和图标；
- 设备名称、类型、图标与上下线提醒选项修改后自动保存；
- 为指定设备开启上线、离线 Windows 系统通知，并可设置通知免打扰时段；
- 可选在 IPv6 连接类型不是 Native 时发送 Windows 系统通知；
- 查看路由器 IPv4、IPv6 上网信息；
- 查看 Mesh 网络中主路由与各节点分别连接的设备数量；
- 在浅色、深色与跟随系统三种主题间即时切换；
- 在应用内重启路由器，并持续显示重启与恢复进度；
- 关闭窗口后继续在系统托盘监控；
- 可选通过当前用户注册表设置登录 Windows 后在托盘中静默启动；
- 防止重复运行，再次打开程序时会直接唤醒已有窗口；
- 使用云母背景、统一圆角控件、轻量动效、细滚动条和圆角托盘菜单。
- 支持用鼠标侧键在设备、路由器和设置界面之间前进与返回。

应用已在小米路由器 AX3000T（RD03，固件 1.0.98）上完成真实接口联调。路由器请求固定绕过系统代理并直连局域网地址，不会改变 Codex、浏览器或其他应用的代理配置。

## 使用

1. 打开 `dist\局域网设备助手\局域网设备助手.exe`。
2. 首次运行时在“设置”中输入路由器地址与管理员密码。
3. 在左侧选择设备，即可查看实时网速、累计用量、连接信息和上下线历史。
4. 在“设备设置”中修改显示名称、类型和图标，并为指定设备开启上线或离线通知；修改后立即生效。
5. 设置页中的路由器地址、管理员密码、刷新间隔、通知免打扰时段、IPv6 提醒、开机自启与界面主题均会在修改后立即应用。
6. 点击右上角“路由器”查看 IPv4/IPv6 与 Mesh 节点信息，或在确认后重启路由器。
7. 在“设置”中可选择是否随 Windows 登录自动启动；从注册表启动时只显示托盘图标，主动双击 EXE 时正常打开主界面。
8. 关闭窗口后，应用默认继续在系统托盘运行；右键托盘图标可打开主界面或退出应用。

> 路由器本地接口不提供安装前的完整上下线历史，因此历史记录从本工具第一次观察到设备时开始积累；已在线设备的本次上线时间会根据路由器返回的在线时长自动回推。

## 隐私与凭据

路由器管理员密码只保存在当前 Windows 用户的凭据管理器中，不写入项目文件、日志或 Git。

## 手机、平板与局域网网页

在电脑端设置中开启“允许局域网设备访问”。默认 HTTPS 端口为 `18732`，证书引导端口为 `18731`，可以更改为两个不同的空闲端口。软件只监听回环和本机私有 IPv4 地址；不会配置公网映射或修改防火墙。Windows 防火墙如出现提示，只允许你信任的专用网络。

1. 手机连接同一局域网，打开设置显示的**证书引导网址**。
2. 将 CA 证书的 SHA-256 指纹与电脑端显示逐字核对，下载并信任证书。也可在电脑端导出公开证书后传到手机。不要仅跳过浏览器安全警告。
3. iOS/iPadOS：安装描述文件后，在“设置 → 通用 → 关于本机 → 证书信任设置”中开启该 CA 的完全信任。安卓的菜单因系统而异，可搜索“安装 CA 证书”；受管理设备和部分浏览器可能不接受用户 CA。
4. 打开 HTTPS 访问网址并输入访问码，或扫描电脑端二维码。二维码/复制链接含访问授权，只能分享给可信设备。
5. 网页只读展示设备、连接类型、实时速率、最近 300 个有效流量采样、最近 100 次上下线会话及 IPv4/IPv6、Mesh 信息。横屏/宽屏双栏，手机竖屏在列表与详情之间切换。

这些步骤不会安装通知接收 App。可信证书是局域网 HTTPS 与浏览器推送的前提；程序不自动向任何设备安装根证书。根私钥与 VAPID 私钥使用 Windows 当前用户 DPAPI 加密保存，公开 `.cer` 不含私钥。CA 有效期 5 年，服务证书有效期 90 天，每次启动服务重新签发，连续运行时会在到期前 7 天自动续签。Windows 用户变更、重装或丢失密钥文件需要重新配置访问和手机信任。不再使用时可在手机设置中删除专用 CA。

电脑需保持运行，关闭窗口到托盘后仍提供网页与推送。停止软件或关闭访问开关后网页不可访问，停止新的推送；已被系统推送服务接受的通知不能撤回。电脑地址改变后点击“应用 / 刷新地址”更新证书与链接；建议在路由器中为电脑保留 IP。网址（含端口）改变后浏览器权限和订阅需要重新建立。

### Web Push 系统通知

- 在电脑端保持“启用网页 Web Push 系统通知”打开。在网页“通知与连接”中点击启用并允许系统通知，再发送测试。
- iPhone/iPad 需要 iOS/iPadOS 16.4 或更新版本，将网页添加到主屏幕，**从主屏幕打开**后启用。Web Push 通过苹果 APNs 投递，不要求额外 App 或 Apple 开发者账号。
- 安卓必须使用支持标准 Web Push 的浏览器。不同系统、浏览器、后台限制和推送网络可达性存在差异，不能保证所有小米、OPPO、vivo 等机型均能收到。需要实际确认锁屏到达。
- 通知遵守电脑端设备的上线/离线提醒选项、IPv6 提醒以及免打扰时段。网页不额外扫描路由器，Mesh 请求由电脑统一每分钟刷新。
- VAPID/Web Push 加密负载通过浏览器厂商的互联网推送服务投递；只接受 Apple、Google FCM、Mozilla、Windows 已知推送域名。无需把监控网页公开到互联网，但电脑及手机需要能连接对应推送服务。
- “推送服务已接受”不等于手机已显示。网页显示实际订阅/发送状态，过期订阅会删除，需重新启用；测试通知间隔至少 15 秒。通知 TTL 为 5 分钟，避免长时间离线后收到陈旧告警。
- 手机离开局域网仍可能收到通知，但打开网页详情必须能访问电脑的局域网地址。
- 关闭本设备通知会删除服务器订阅；电脑“重置所有网页授权”会更换访问码并撤销全部订阅。浏览器自身的系统权限不会被远程修改。

官方依据：[Apple Web Push](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers)、[WebKit iOS/iPadOS 主屏幕支持](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)。

## 本地构建

运行 `scripts\build.ps1` 构建，运行 `scripts\publish.ps1` 生成 Release 产物。脚本优先使用项目内 `.tools\dotnet` SDK，并把发布结果放到 `dist\局域网设备助手`。

应用图标由 `scripts\GenerateIcon.ps1` 生成，源文件输出到 `src\LanDeviceMonitor.App\Assets\AppIcon.ico`。
