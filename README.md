# 局域网设备助手

一个面向 Windows 11 的原生桌面工具，通过小米路由器管理接口查看局域网设备。

## 功能

- 实时查看设备在线状态、上传/下载速度和累计流量；
- 从工具首次运行起持续记录设备上线与离线历史；
- 根据路由器设备名识别手机、电脑、空调、灯、插座、音箱、路由器等设备类型；
- 自定义设备名称、类型和图标；
- 设备名称、类型、图标与上下线提醒选项修改后自动保存；
- 为指定设备开启上线、离线 Windows 系统通知，并可设置通知免打扰时段；
- 可选在 IPv6 连接类型不是 Native 时发送 Windows 系统通知；
- 查看路由器 IPv4、IPv6 上网信息；
- 查看 Mesh 网络中主路由与各节点分别连接的设备数量；
- 在浅色、深色与跟随系统三种主题间即时切换；
- 在应用内重启路由器，并持续显示重启与恢复进度；
- 关闭窗口后继续在系统托盘监控；
- 可选通过当前用户注册表设置登录 Windows 后在托盘中静默启动；
- 防止重复运行，再次打开程序时会直接唤醒已有窗口；
- 使用云母背景、统一圆角控件、轻量动效、细滚动条和圆角托盘菜单。
- 支持用鼠标侧键在设备、路由器和设置界面之间前进与返回。

应用已在小米路由器 AX3000T（RD03，固件 1.0.98）上完成真实接口联调。路由器请求固定绕过系统代理并直连局域网地址，不会改变 Codex、浏览器或其他应用的代理配置。

## 使用

1. 打开 `dist\局域网设备助手\局域网设备助手.exe`。
2. 首次运行时在“设置”中输入路由器地址与管理员密码。
3. 在左侧选择设备，即可查看实时网速、累计用量、连接信息和上下线历史。
4. 在“设备设置”中修改显示名称、类型和图标，并为指定设备开启上线或离线通知；修改后立即生效。
5. 设置页中的路由器地址、管理员密码、刷新间隔、通知免打扰时段、IPv6 提醒、开机自启与界面主题均会在修改后立即应用。
6. 点击右上角“路由器”查看 IPv4/IPv6 与 Mesh 节点信息，或在确认后重启路由器。
7. 在“设置”中可选择是否随 Windows 登录自动启动；从注册表启动时只显示托盘图标，主动双击 EXE 时正常打开主界面。
8. 关闭窗口后，应用默认继续在系统托盘运行；右键托盘图标可打开主界面或退出应用。

> 路由器本地接口不提供安装前的完整上下线历史，因此历史记录从本工具第一次观察到设备时开始积累；已在线设备的本次上线时间会根据路由器返回的在线时长自动回推。

## 隐私与凭据

路由器管理员密码只保存在当前 Windows 用户的凭据管理器中，不写入项目文件、日志或 Git。

## 手机、平板与局域网网页

1. 在电脑端设置中开启“允许局域网设备访问”。
2. 手机或平板连接同一局域网，扫描二维码，或打开旁边的链接。
3. 直接查看设备状态、连接信息、网速、流量曲线、上下线历史及路由器 IPv4/IPv6、Mesh 信息。

无需账号、访问码、证书、域名、云服务或额外 App；端口自动选择，被占用时自动避让。网页支持手机竖屏、横屏及平板，所有资源随软件打包，运行不需要访问外部网站。流量图保留最近 300 个有效采样，上下线记录显示最近 100 次会话。

开启后，同一局域网内能连接电脑的设备均可只读访问这些信息；请只在信任的局域网中开启。电脑需保持运行，关闭窗口到托盘后仍可访问；关闭开关或退出软件后停止服务。没有网卡时仅本机可访问，网络或电脑 IP 变化后重新开启即可更新链接。Windows 防火墙若询问网络访问，请允许专用网络；访客网络隔离可能阻止手机连接电脑。

手机推送功能已移除，网页没有通知权限申请、推送订阅或证书安装步骤。现有 Windows 系统通知及免打扰规则不变。旧版生成的本机加密网页配置不再读取，也不会自动删除；软件从未自动安装系统根证书，若用户曾手动在手机安装旧 CA，可以自行删除。
## 本地构建

运行 `scripts\build.ps1` 构建，运行 `scripts\publish.ps1` 生成 Release 产物。脚本优先使用项目内 `.tools\dotnet` SDK，并把发布结果放到 `dist\局域网设备助手`。

应用图标由 `scripts\GenerateIcon.ps1` 生成，源文件输出到 `src\LanDeviceMonitor.App\Assets\AppIcon.ico`。
